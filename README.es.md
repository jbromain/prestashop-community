# PrestaShop Community Edition

Distribución de código abierto de la plataforma de comercio electrónico PrestaShop, empaquetada sin los módulos propietarios distribuidos por PrestaShop SA.

## Descripción general

Este repositorio aloja las compilaciones comunitarias de PrestaShop, generadas a partir del código fuente original disponible en [github.com/PrestaShop/PrestaShop](https://github.com/PrestaShop/PrestaShop/).

Las compilaciones se elaboran manualmente cada vez que se publica oficialmente una nueva versión upstream. Por este motivo, las publicaciones de este repositorio pueden aparecer con un breve retraso respecto al proyecto original.

**Última versión disponible:** `9.1.1` (estable)

## ¿Qué es PrestaShop Community Edition?

A partir de PrestaShop 9, PrestaShop SA distribuye una única compilación oficial que agrupa el núcleo de código abierto junto con varios módulos propietarios.

Dichos módulos están orientados a fines comerciales y **no son necesarios** para el funcionamiento de la plataforma. En algunos casos introducen una sobrecarga adicional y pueden degradar el rendimiento de la tienda.

La edición Community publicada en este repositorio contiene **únicamente** el proyecto de código abierto y sus módulos estándar; no se incluye ningún componente propietario.

## Instalación

1. Descargue el archivo de la versión deseada (`.zip`) desde la sección [Releases](https://github.com/jbromain/prestashop-community/releases).
2. Descomprima el archivo y suba su contenido a su servidor web.
3. Acceda al directorio de instalación desde un navegador. El instalador de PrestaShop se iniciará y le guiará durante el proceso de configuración.
