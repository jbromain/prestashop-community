# PrestaShop Community Edition

An open-source distribution of the PrestaShop e-commerce platform, packaged without the proprietary modules shipped by PrestaShop SA.

## Overview

This repository hosts community builds of PrestaShop, compiled from the upstream source at [github.com/PrestaShop/PrestaShop](https://github.com/PrestaShop/PrestaShop/).

Builds are produced manually whenever a new upstream version is officially released. As a result, releases in this repository may be published with a short delay relative to the upstream project.

**Latest available version:** `9.1.1` (stable)

## What is the PrestaShop Community Edition?

Starting with PrestaShop 9, PrestaShop SA distributes a single official build that bundles the open-source core together with several proprietary modules.

These bundled modules are intended for commercial purposes and are **not required** for the platform to operate. In some cases they introduce additional overhead and may degrade store performance.

The Community Edition published in this repository contains **only** the open-source project and its standard modules — no proprietary components are included.

## Installation

1. Download the desired release archive (`.zip`) from the [Releases](https://github.com/jbromain/prestashop-community/releases) section.
2. Extract the archive and upload its contents to your web server.
3. Open the installation directory in a web browser. The PrestaShop installer will launch and walk you through the setup process.
